# Security Policy

`dbshift` takes the security of our users and their database data seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within `dbshift`, please do **NOT** open a public issue.

Instead, please send an advisory report to:
- **GitHub Security Advisory:** Submit privately via [GitHub Security Advisories](https://github.com/dusmamud/dbshift/security/advisories)
- **Maintainer:** Contact [dusmamud](https://github.com/dusmamud)

### What to Include in Your Report
1. A clear description of the vulnerability.
2. Steps to reproduce or proof-of-concept (PoC).
3. The affected version of `dbshift`.
4. Any potential mitigations you have identified.

### Response Time
We will acknowledge receipt of your vulnerability report within **48 hours** and provide regular updates until the vulnerability is resolved and a patched release is published.
